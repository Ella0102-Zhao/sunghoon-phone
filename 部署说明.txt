部署内容：朴成训手机互动模拟器（完整静态网页）

上传要求：
1. 必须保持 index.html 与 assets 文件夹的相对位置不变。
2. 托管平台需按静态网站方式发布，入口文件为根目录 index.html。
3. 请勿只上传 index.html，否则图片、音乐和音效会缺失。
4. 页面已使用固定 430 × 932 设计画布，并按视口等比缩放以适配手机与电脑。
5. 音频文件为 M4A；托管平台应以 audio/mp4 或 audio/mp4a-latm 类型提供。
6. 手机浏览器通常要求用户先点击页面，之后才允许播放音乐或音效。

GitHub Pages：本项目通过 GitHub Actions 解压 site.zip 并发布。
