朴成训 iPhone 模拟器——部署说明

一、必须部署哪一层

请把本文件所在的 sunghoon-phone-upload 文件夹作为“网站根目录”。
网站根目录中必须直接看到：

index.html
assets/
.openai/hosting.json

不能把上一级 work 文件夹设为网站根目录，也不能只上传 index.html。
如果平台要求填写 Publish directory / Output directory，请填写：.
入口文件固定为：index.html

二、使用 ZIP 上传时

请使用 sunghoon-phone-upload.zip。
解压后，压缩包第一层应直接出现 index.html 和 assets 文件夹。
如果解压后还需要连续打开 work/sunghoon-phone-upload 才能看到 index.html，说明上传层级错误。

三、托管类型

这是纯静态 HTML 网站：

- 不需要 npm install。
- 不需要构建命令。
- Framework preset 选择 None / Other / Static HTML。
- Build command 留空。
- Publish directory 填写 .
- 不要选择 Next.js、React、Vue 或 Node Server 模式。

四、资源要求

assets 文件夹必须完整上传，并和 index.html 保持同级。
不要单独移动、重命名或二次压缩 assets 内的图片、音乐和音频文件，否则图标、照片或音乐会丢失。

五、手机端交互

- 页面内部固定使用 430×932 的现代 iPhone 设计画布，手机和电脑只对整台设备进行等比缩放；托管平台不要再套用 iframe 缩放、固定宽高或移动端重排规则。
- 锁屏从底部向上滑进入密码页。
- 应用内从底部白色横条区域向上滑返回桌面。
- 手机使用手指滑动；电脑预览使用鼠标从底部向上拖动。
- 页面内部列表正常上下滚动，不应被托管平台添加额外滚动容器。
- 请保留 index.html 中的 viewport 设置，不要让托管平台注入固定桌面宽度、页面缩放标签或覆盖 transform。
- 手机浏览器中，时间固定在灵动岛左侧，信号、Wi‑Fi 和电池固定在右侧；通话等待和接通后的六个按钮都固定在底部。
- 电脑预览使用现有桌面布局，手机适配不会改变电脑端的正常位置。

六、HTTPS 与相机

相机功能只有在 HTTPS 网站或 localhost 中才能请求摄像头权限。
部署完成后，需要由玩家在浏览器中允许摄像头权限。

七、部署后检查

请依次确认：

1. 首页没有 404，壁纸和所有 App 图标正常显示。
2. 手机外壳保持窄长比例，没有被横向拉宽。
3. 锁屏可以向上滑动。
4. 打开任意 App 后，可以从底部横条向上滑回桌面。
5. KakaoTalk、电话、信息、音乐和相册资源均能加载。
6. 浏览器开发者工具中没有 assets 路径的 404。

八、本地数据说明

玩家昵称、上传头像、临时聊天、拍摄照片和设置只保存在当前浏览器会话或本地浏览器中，不会上传到服务器；刷新或更换设备后，部分临时内容会重置。
